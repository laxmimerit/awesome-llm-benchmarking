### ANSWER
Prevent SQL injection by **never building SQL with user input via string concatenation or f-strings**. Instead, use **parameterized queries / prepared statements**, where the database driver sends the SQL structure and the data separately.

## Core rule

Unsafe:

```python
name = request.args.get("name")

# BAD: SQL injection risk
sql = f"SELECT * FROM users WHERE name = '{name}'"
cursor.execute(sql)
```

Safe:

```python
name = request.args.get("name")

# GOOD: parameterized query
cursor.execute("SELECT * FROM users WHERE name = %s", (name,))
```

The exact placeholder style depends on the database driver.

# 1. SQLite with `sqlite3`

SQLite uses `?` placeholders.

```python
import sqlite3

def get_user(user_id: int):
    conn = sqlite3.connect("app.db")
    cur = conn.cursor()

    cur.execute(
        "SELECT id, username, email FROM users WHERE id = ?",
        (user_id,)
    )

    user = cur.fetchone()
    conn.close()
    return user
```

Multiple parameters:

```python
cur.execute(
    """
    SELECT id, username, email
    FROM users
    WHERE username = ?
      AND email = ?
    ORDER BY id
    LIMIT ?
    """,
    (username, email, limit)
)
```

Insert:

```python
cur.execute(
    "INSERT INTO users (username, email) VALUES (?, ?)",
    (username, email)
)
```

Update:

```python
cur.execute(
    "UPDATE users SET email = ? WHERE id = ?",
    (new_email, user_id)
)
```

Delete:

```python
cur.execute(
    "DELETE FROM users WHERE id = ?",
    (user_id,)
)
```

# 4. SQLAlchemy Core

SQLAlchemy Core uses named parameters with `text()`.

```python
from sqlalchemy import create_engine, text

engine = create_engine("postgresql://myuser:mypassword@localhost/mydb")

def get_user(user_id: int):
    with engine.connect() as conn:
        result = conn.execute(
            text("SELECT id, username, email FROM users WHERE id = :user_id"),
            {"user_id": user_id}
        )
        return result.fetchone()
```

Multiple parameters:

```python
result = conn.execute(
    text("""
        SELECT id, username, email
        FROM users
        WHERE username = :username
          AND email = :email
        ORDER BY id
        LIMIT :limit
    """),
    {
        "username": username,
        "email": email,
        "limit": limit
    }
)
```

Insert:

```python
conn.execute(
    text("INSERT INTO users (username, email) VALUES (:username, :email)"),
    {"username": username, "email": email}
)
conn.commit()
```

Update:

```python
conn.execute(
    text("UPDATE users SET email = :email WHERE id = :user_id"),
    {"email": new_email, "user_id": user_id}
)
conn.commit()
```

Delete:

```python
conn.execute(
    text("DELETE FROM users WHERE id = :user_id"),
    {"user_id": user_id}
)
conn.commit()
```
